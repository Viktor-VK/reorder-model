# Глоссарий столбцов

Названия столбцов, которые появляются в таблицах ноутбука и созданы в расчётах (не из исходных листов Excel - те описаны в `data_dictionary.xlsx`). Метрики бэктеста и базовые величины модели (`S`, `InventoryPosition`, `RecommendedOrder`, `protection_period_days`, `available_to_cover`, `cycle_service_level`, `fill_rate`, `avg_inventory`, `max_inventory`, `shortfall`, `excess`) здесь не дублируются - они определены в README, в разделе "Метрики".

- **actual_demand** — реальные продажи SKU, случившиеся за protection period после `control_date` (факт, с которым сверяется решение модели).
- **actual_stock_fact** — реальный суммарный остаток по всем SKU на дату `target_date`, для сравнения с расчётной проекцией.
- **control_date** — дата, на которую принято решение (контрольная дата бэктеста).
- **cycle_success** — булев флаг: `True`, если за цикл дефицита не было вообще (`shortfall == 0`); из него считается Cycle Service Level.
- **days_total** — число дней в истории у SKU (обычно 457, если не сужен `SELECTED_SKUS`).
- **days_with_sales** — сколько из этих дней были с продажами (`SalesQty > 0`).
- **demand_over_protection** — ожидаемый спрос за protection period без страхового запаса (`mean_daily_sales × protection_period_days`).
- **Комментарий** — пояснение к рекомендации, если она требует ручной проверки (сейчас - только для 18 SKU без истории продаж).
- **mean_daily_sales** — среднесуточный спрос по всей истории (`total_sales / days_total`), основа наивной оценки спроса.
- **mean_daily_weighted** — средневзвешенный дневной спрос по недавней истории (ближние дни с весом `RECENT_WEIGHT_NEAR`, дальние - с остатком веса).
- **model** — название модели/сценария в строке сводной таблицы (например, "z x std (SL=95%)") - подпись, а не измеряемая величина.
- **outlier_counts_by_sku** — число найденных выбросов продаж (правило Q3+3×IQR) на каждый SKU.
- **projected_stock_model** — расчётный остаток по модели на `target_date` (`available_to_cover − actual_demand`); может быть отрицательным - это и есть дефицит.
- **RecommendedOrder_baseline** — то же, что `RecommendedOrder` из README, но для baseline-модели (суффикс - чтобы не путать с колонкой доработанной модели в соседних таблицах).
- **S_baseline** — то же, что `S` из README, но для baseline-модели.
- **share_days_with_sales** — доля дней с продажами (`days_with_sales / days_total`) - индикатор прерывистости спроса.
- **stock_filled** — остаток на конец дня с заполненными пропусками (forward fill внутри каждого SKU).
- **stock_gap** — разница `CurrentStock − последний известный остаток истории` по каждому SKU.
- **target_date** — дата, на которую спроецирован остаток (`control_date + protection_period_days`) - момент прихода следующего заказа.
